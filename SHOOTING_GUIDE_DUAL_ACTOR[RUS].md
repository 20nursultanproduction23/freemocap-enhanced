# Руководство по съемке двух актёров — FreeMoCap Enhanced v3.2

Полное пошаговое руководство по одновременной записи двух людей с использованием маркерного захвата движения.

---

## 1. ПОДГОТОВКА ПОМЕЩЕНИЯ

### 1.1 Требования к пространству

- **Минимальная площадь**: 3м x 3м свободного пространства (идеально 4м x 4м)
- **Высота потолка**: не менее 2.5м
- Убрать все предметы между камерами и зоной захвата (стулья, столы, коробки)
- **Пол**: однородный цвет, без отражающих поверхностей (зеркало, стекло, полированный металл)
- **Стены**: избегать больших зеркал или окон, создающих блики

### 1.2 Освещение

- **Равномерное, рассеянное освещение** из нескольких источников — без резких теней
- Избегать прямого солнечного света (изменяется во время записи)
- Избегать одиночного верхнего светильника (создает сильные тени под подбородком, руками)
- **Рекомендуется**: 2-4 мягких LED-панели под разными углами, или верхний люминесцентный + боковой заполняющий
- Цветовая температура света должна быть одинаковой (все теплые или все холодные, не смешивать)

### 1.3 Расположение камер

```
                    [Камера 0 - Фронтальная]
                          |
                          |
                          v

[Камера 1 - Левая] <--- [ АКТЁРЫ ] ---> [Камера 2 - Правая]
```

- **Минимум 3 камеры** (больше = лучше триангуляция)
- Расположить камеры **на уровне глаз или чуть выше** (1.5-1.8м высота)
- Камеры должны иметь **перекрывающиеся поля зрения**, покрывающие всю зону захвата
- Наклон камер **15-30 градусов вниз** к центру зоны захвата
- **Расстояние до актёров**: 2-4 метра в зависимости от фокусного расстояния объектива
- Убедиться, что каждая камера видит **обоих актёров одновременно**

### 1.4 Синхронизация камер

- Все камеры должны начать запись в **точно тот же кадр**
- Использовать аппаратную синхронизацию, если доступна (кабель триггера, генлок)
- Если нет аппаратной синхронизации: запускать все камеры в пределах **1-2 кадров** друг от друга
- Все камеры должны работать на **одинаковой частоте кадров** (например, все 30fps или все 60fps)
- Все камеры должны иметь **одинаковое разрешение**

## 2. ПОДГОТОВКА АКТЁРОВ

### 2.1 Одежда

| МОЖНО | НЕЛЬЗЯ |
|---|---|
| Обтягивающая одежда одного цвета | Свободная/мешковатая одежда (скрывает форму тела) |
| Длинные рукава + длинные штаны (лучше трекинг) | Шорты + майка (кожа сбивает детектор) |
| Матовая ткань (хлопок, полиэстер) | Блестящая/отражающая ткань (атлас, кожа) |
| Темные или яркие однотонные цвета | Всее черное или все белое (сложно отличить от фона) |
| Обувь на плоской подошве или босиком | Туфли на каблуке, платформы |

### 2.2 ArUco Маркеры (ВАЖНО для режима двух актёров)

ArUco маркеры помогают системе определить **кто есть кто**, когда актёры пересекаются или кратковременно закрывают друг друга.

**Как сгенерировать маркеры:**
```bash
cd freemocap_enhanced
python tools/generate_actor_markers.py
```
Создаст печатные изображения маркеров в папке `markers/`.

**Как носить маркеры:**
- Распечатать маркеры размером **А5 или А4**
- Приклеить или закрепить **один маркер на актёра** на переднюю часть торса (уровень груди)
- Маркер должен быть **плоским, не изогнутым** — используйте картонную подложку при необходимости
- **Актёр А**: маркер ID 0 (обычно шаблон в левом верхнем углу)
- **Актёр Б**: маркер ID 1 (обычно шаблон в правом верхнем углу)
- **Критично**: маркеры должны быть видны **минимум из 2 камер** постоянно

```
    Актёр А                    Актёр Б
  ┌──────────┐              ┌──────────┐
  │ ┌──────┐ │              │ ┌──────┐ │
  │ │ID: 0 │ │              │ │ID: 1 │ │
  │ └──────┘ │              │ └──────┘ │
  │  (грудь) │              │  (грудь) │
  └──────────┘              └──────────┘
```

### 2.3 Максимальное расстояние между актёрами

- Актёры должны находиться в пределах **1.5м друг от друга** для оптимальной кросс-камерной ассоциации
- Могут двигаться до **3м друг от друга**, но качество ассоциации может снизиться
- **Никогда не поворачиваться спиной друг к другу** дольше 2-3 секунд (маркеры теряют видимость)

## 3. НАСТРОЙКА ПРОГРАММЫ

### 3.1 Запуск приложения

```bash
cd freemocap_enhanced
venv\Scripts\activate          # Активировать виртуальное окружение
python run_freemocap_enhanced.py
```

Дождитесь загрузки. Вы увидите:
1. Главное окно FreeMoCap
2. Оригинальное окно приветствия — нажмите **Done**
3. Enhanced экран приветствия — закройте или переключите язык (RU/EN)
4. Заметки о последних обновлениях (при первом запуске) — нажмите **OK**

### 3.2 Выбор режима двух актёров

1. Нажмите **"New Recording"** в верхнем меню (или на панели инструментов)
2. Появится экран **"Выбор режима"**
3. Выберите режим **"Dual Actor"** (Два актёра)
4. Нажмите **Далее**

### 3.3 Настройка камер

1. Переключитесь на вкладку **"Camera View"**
2. Нажмите **"Detect Cameras"** — все подключённые камеры должны появиться
3. Убедитесь, что вы видите ** live-потоки со ВСЕХ камер**
4. Проверьте, что **оба актёра видны на каждой камере**
5. Если камера не обнаружена:
   - Проверьте USB-подключение
   - Закройте другие приложения, использующие камеру
   - Перезапустите приложение

### 3.4 Калибровка камер (ПЕРВЫЙ РАЗ)

Калибровка определяет позиции камер в 3D-пространстве. Нужно делать **только один раз**, пока камеры не сдвинулись.

**Калибровочный паттерн**: используйте распечатанный CharUco-паттерн (рекомендуется размер А3)

Шаги:
1. Распечатайте CharUco-паттерн (минимум 7x10 квадратов)
2. Держите паттерн **плоско** перед Камерой 0
3. Медленно поворачивайте под разными углами (наклон ±30°, поворот ±30°)
4. Захватывайте **20-30 кадров** на каждую камеру
5. Повторите для Камеры 1, Камеры 2 и т.д.
6. Система вычислит матрицы камер и экстраксики
7. Сохраните калибровку в файл `.toml`

**Чек-лист качества калибровки:**
- [ ] На каждую камеру минимум 20 калибровочных кадров
- [ ] Паттерн показан под разными углами (не только анфас)
- [ ] Паттерн занимает минимум 30% кадра
- [ ] Нет размытия движения в калибровочных кадрах (держите неподвижно!)
- [ ] Ошибка репроекции < 2.0 пикселей (показывается в выводе калибровки)

## 4. СЕССИЯ ЗАПИСИ

### 4.1 Чек-лист перед записью

```
ПОМЕЩЕНИЕ:
  [ ] Зона захвата свободна от препятствий
  [ ] Освещение равномерное, нет резких теней
  [ ] Пол чистый, однородного цвета

КАМЕРЫ:
  [ ] Все камеры подключены и обнаружены
  [ ] Все камеры показывают live-поток
  [ ] Оба актёра видны на ВСЕХ камерах
  [ ] Все камеры на одинаковой частоте кадров и разрешении
  [ ] Калибровка выполнена (первый раз) или загружена

АКТЁРЫ:
  [ ] Одежда обтягивающая, однотонная
  [ ] ArUco маркеры прикреплены к груди (если используются)
  [ ] Маркеры видны минимум из 2 камер
  [ ] Актёры отрепетировали постановку

ПРОГРАММА:
  [ ] FreeMoCap Enhanced запущен
  [ ] Режим Dual Actor выбран
  [ ] Папка для записи выбрана
```

### 4.2 Начало записи

1. Откройте вкладку **"Camera View"**
2. Оба актёра встают на **стартовые позиции** в центре зоны захвата
3. Актёры поворачиваются **лицом к основной камере** (Камера 0)
4. Актёр А стоит **слева**, актёр Б **справа** (с точки зрения Камеры 0)
5. Актёры стоят **1-1.5м друг от друга**, бок о бок
6. Нажмите **красную кнопку "Record"**
7. Появится обратный отсчёт **3-2-1**
8. Запись начнётся — вы увидите счётчик кадров

**ВАЖНО**: Первые **2-3 секунды** записи служат **эталонной позой** — актёры должны стоять неподвижно в T-pose или A-pose для лучших результатов.

```
T-pose (рекомендуется):        A-pose (альтернатива):
       |                            |
    ---+---                       \ | /
       |                           \|/
    ---+---                         |
       |                            |
      / \                          / \
```

### 4.3 Во время записи

**Актёры должны:**
- Двигаться **медленно и плавно** (избегать резких рывков)
- Оставаться в **перекрывающемся поле зрения камер** (центральная зона)
- Держать **руки в стороне от торса** когда возможно (лучше трекинг)
- Избегать **поворота спиной** к камерам на длительное время
- Если нужно пересечь paths: **обходить друг друга**, а не проходить сквозь
- Держать движения в пределах **2м x 2м центральной зоны** для лучших результатов

**Актёрам НЕЛЬЗЯ:**
- Бегать или делать очень быстрые движения
- Приседать или ложиться на пол (кроме как постановочно)
- Носить или нести предметы, скрывающие тело (сумки, крупные реквизиты)
- Долго трогать или хватать друг друга (краткое рукопожатие ОК, длительная борьба сбивает трекер)

**Оператор камеры должен:**
- Следить за live-потоками всех камер на предмет неполадок
- Смотреть на счётчик кадров — хорошая запись длится **10-60 секунд** за дубль
- Если live-поток камеры пропал — **остановитесь и проверьте** подключение

### 4.4 Окончание записи

1. Актёры возвращаются на **стартовую позицию** (опционально, для чистого монтажа)
2. Нажмите кнопку **"Stop"**
3. Дождитесь, пока статус-бар покажет **"Saving..."** — НЕ закрывайте приложение
4. Дождитесь подтверждения **"Recording saved"**
5. Запись сохранена в выбранную папку

### 4.5 Пост-обработка после записи

После остановки записи:

1. Переключитесь на вкладку **"Process"**
2. Выберите только что сделанную запись
3. Нажмите **"Process Motion Capture Data"**
4. Запустится пайплайн:
   - Стадия 1: Мульти-персональная детекция (RTMDet + RTMPose) — ~2-5 мин
   - Стадия 2: Кросс-камерная ассоциация — ~10-30 сек
   - Стадия 3: Временной трекинг — ~10-30 сек
   - Стадия 4: Триангуляция DLT для каждого актёра — ~30-60 сек
   - Стадия 5: v3.1 пост-обработка — ~1-3 мин
5. Дождитесь сообщения **"Processing complete"**
6. Результаты появятся на вкладке **"3D Viewer"**

**Время обработки зависит от:**
- Количества кадров (больше = медленнее)
- Количества камер (больше = медленнее, но точнее)
- Скорости GPU (NVIDIA GPU значительно быстрее)
- Скорости CPU (для stages без GPU)

Типично: **10-20 минут** для 30-секундной записи на 30fps с 3 камерами.

## 5. УСТРАНЕНИЕ ПРОБЛЕМ

### Частые проблемы

| Проблема | Причина | Решение |
|----------|---------|---------|
| Актёры меняют ID в середине записи | Недостаточно ArUco маркеров | Прикрепить маркеры к груди, обеспечить видимость |
| Один актёр не детектируется | Закрыт из большинства камер | Переставить камеры или актёров |
| Скелет "дрожит" сильно | Проблема синхронизации камер | Проверить что все камеры на одной частоте кадров |
| Дыры/пропуски в скелете | Актёр слишком долго закрыт | Переделать, актёрам быть более видимыми |
| Артефакт "дышащих костей" | Пайплайн не применён | Перезапустить с v3.2 пост-обработкой |
| Стопа скользит по полу | Нет блокировки стопы | Включить коррекцию скольжения стопы в пайплайне |
| Два скелета сливаются в один | Актёры слишком близко | Увеличить расстояние до >1м, добавить ArUco маркеры |

### Советы по записи

- **Делайте 3-5 дублей** каждой постановки — выбирайте лучший
- **Дубли должны быть короткими**: 15-30 секунд — оптимально для качества
- **Подписывайте записи** понятно в названии папки
- **Сохраняйте калибровку** после хорошей сессии — пересоздавайте при повторных съемках
- **Тестируйте с 1 актёром сначала**, чтобы проверить камеры, затем переключайтесь на Dual Actor
