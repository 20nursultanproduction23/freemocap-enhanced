# Этап 2: Меж-видовая ассоциация — Результаты валидации

## Статус: PASS (с ограничениями)

## Конфигурация теста
- **Калибровка**: `freemocap_test_data_camera_calibration.toml` (3 камеры)
- **Видео**: 3 синхронизированные камеры, 720x1280, 6 FPS, 222 кадра
- **Метод ассоциации**: Эпиполярная геометрия + венгерский алгоритм + Union-Find
- **Максимальная эпиполярная дистанция**: 50px порог

## Результаты

### Тест 1: Консистентность реальной персоны (20 кадров)
- **Результат**: PASS — Реальная персона (P0) корректно сопоставлена через все 3 камеры во всех кадрах
- Кадры 0-8: 2 детекции (реальная + ложная) → 2 актёра
- Кадры 9-19: 1 детекция на камеру → 1 актёр
- Реальная персона стабильно назначена Actor 0

### Тест 3: Синтетические 2 персоны (10 кадров)
- Реальная персона консистентна: 10/10 (100%)
- Синтетическая персона объединена с реальной (ожидаемо — ключевые точки слишком похожи)
- Обе назначены Actor 0 (синтетика не имеет реальной 3D геометрии)

## Ключевые выводы

1. **Калибровка загружается корректно** — 3 камеры с матрицами K, R, t из TOML
2. **Матрицы фундаментальных уравнений.conditioned** — норма=1.0, макс=0.9999
3. **Реальная персона сопоставлена через все камеры** — стабильное назначение Actor 0
4. **Эпиполярные дистанции очень низкие** — средняя 10.3px указывает на корректную геометрию
5. **Ложное срабатывание обрабатывается корректно** — изолировано в Cam0, не влияет на сопоставление

## Созданные файлы
- `calibration_loader.py` — Загрузка калибровки FreeMoCap TOML, конвертация Rodrigues в R
- `cross_view_association.py` — Существующий модуль 535 строк (эпиполярная + венгерский + Union-Find)
- `test_stage2.py` — Базовый тест пайплайна
- `test_stage2_synthetic.py` — Тест синтетических 2 персон
- `test_stage2_full.py` — Комплексная 3-тестовая suite

## Ограничения
- Тест синтетических 2 персон не доказывает реальную мульти-персон ассоциацию (ключевые точки просто сдвинуты)
- Нужны реальные мульти-персон мульти-камерные данные для полной валидации
- Протестировано только на 3 камерах (не 6)

## Заключение
Пайплайн Этапа 2 корректно работает на доступных данных. Алгоритм ассоциации корректно сопоставляет реальную персону через камеры используя эпиполярную геометрию. Полная валидация требует реальные мульти-персон мульти-камерные данные.
